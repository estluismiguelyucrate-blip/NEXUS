# NEXUS 2.0

## Descripción
NEXUS 2.0 es un proyecto desarrollado para la asignatura de Programación II. Este repositorio contiene el código fuente y los archivos necesarios para documentar su funcionamiento.

## Tecnologías
- C#
- .NET
- Visual Studio Community

## Estructura del proyecto
- `Programa.cs`: contiene el código principal del proyecto.
- `NEXUS 2.0.csproj`: contiene la configuración del proyecto.
- `.gitignore`: especifica los archivos y carpetas que no deben publicarse.

## Cómo ejecutar el proyecto
1. Instalar Visual Studio Community con la carga de trabajo de desarrollo de escritorio de .NET, si corresponde.
2. Descargar o clonar este repositorio.
3. Abrir `NEXUS 2.0.csproj` en Visual Studio.
4. Restaurar las dependencias, si fueran necesarias.
5. Ejecutar el proyecto.

## Documentación
La carpeta `docs/` contendrá el manual técnico, los diagramas y la guía de estudio para el Hito 3.
